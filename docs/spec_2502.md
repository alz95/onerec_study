# Reproduction Spec: OneRec (arXiv:2502.18965)

## 1. Scope

This spec tracks implementation choices for a compact OpenOneRec-aligned baseline.
Target dataset in this repo: **MovieLens-1M**.

## 2. What is now aligned

- [x] Encoder-decoder training path (not encoder-only retrieval scorer)
- [x] Sparse MoE-style decoder FFN (top-1 routing)
- [x] Session generation interface (`generate_session`)
- [x] Preference-style objective option (`dpo` pair loss)
- [x] Standard baseline ranking metrics and comparable split/eval protocol

## 3. Protocol used for comparability

- Dataset: MovieLens-1M
- Split: leave-one-out by timestamp
  - train: all but last 2 interactions
  - val target: penultimate
  - test target: last
- Evaluation modes:
  - sampled ranking: 1 positive + N unseen negatives
  - all-item ranking: full catalog, optional seen-item filtering
- Metrics: HR@K / Recall@K / NDCG@K

## 4. Remaining gaps vs full OpenOneRec

- exact semantic tokenization / quantization and indexing pipeline
- full reward model and iterative preference alignment workflow
- exact expert routing/sparsity/load-balancing losses from official stack
- exact training schedule and distributed system-level optimizations

## 5. Experiment plan

1. run `generative_ce` / `bpr` / `dpo` on same split and eval mode
2. compare sampled vs all-item rankings under same checkpoint
3. report mean/std across multiple random seeds
