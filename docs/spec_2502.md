# Reproduction Spec: OneRec (arXiv:2502.18965)

## 1. Scope

This spec translates the paper into implementable engineering checkpoints.
Current repository status: **phase-1 scaffold**.

## 2. Reproduction goals

### Must-have
- End-to-end train/eval/test loop runs stably.
- Report Recall@K and NDCG@K under a fixed protocol.
- Reproducible with explicit seeds and saved config.

### Nice-to-have
- Ablation trend consistency with the paper.
- Hyperparameter sensitivity broadly consistent with reported findings.

## 3. Protocol checklist (to complete)

- [ ] Dataset(s): exact names and preprocessing filters from paper
- [ ] Split: leave-one-out or time-aware split, paper-consistent
- [ ] Negative sampling: distribution and count
- [ ] Evaluation filtering rules (seen-item filtering)
- [ ] Main objective and auxiliary objectives
- [ ] Training schedule (warmup, decay, clipping)

## 4. Implementation plan

1. **Baseline loop (done)**
   - Sequential encoder + item scoring
   - BPR training objective
   - Recall/NDCG metrics
2. **Paper alignment (next)**
   - Plug in paper-specific architecture components
   - Add exact loss composition
   - Add exact sampler/evaluator behavior
3. **Experiment rigor**
   - Multi-seed runner
   - Config snapshots
   - Result table generator

## 5. Risks to monitor

- Split protocol mismatch (highest impact)
- Negative sampling mismatch
- Evaluation filtering mismatch
- Hidden optimizer/scheduler details
